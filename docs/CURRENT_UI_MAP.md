# Карта текущего UI

Практический индекс ответственности за текущий визуальный слой. «Да» означает,
что правка представления обычно входит в scope fork; «Осторожно» — что файл
также управляет взаимодействием, инфраструктурой layout или внешним поведением.

## Управление через конфигурацию — в первую очередь

Активный `config.toml` без изменения репозитория меняет палитру, шрифт,
масштаб, поверхность панели, opacity, radius, margin, opacity/backdrop меню,
включение анимаций и композицию модулей left/centre/right.

Для исходного кода начинайте со строки компонента, напрямую владеющего нужным
визуальным оформлением. Переходите в `src/theme.rs` только когда стиль должен
быть единым для нескольких компонентов.
